## 🚀 Featured work — the FitCPX ecosystem

I designed and developed **[FitCPX](https://fitcpx.com)**, a software platform for gyms, personal trainers, and fitness professionals. Its ecosystem covers student management, workout planning, physical assessments, scheduling, contracts, subscriptions, payments, reporting, and mobile experiences.

The public repositories below show different parts of that work, with their **original development histories preserved**:

| Repository | What it demonstrates | Main technologies |
| --- | --- | --- |
| 🌐 **[FitCPX Web](https://github.com/Allyyssoonnn/fitcpx-web)** | Web interface for fitness professionals and business operations | React, TypeScript, Vite |
| ⚙️ **[FitCPX Backend](https://github.com/Allyyssoonnn/fitcpx-backend)** | API, data modeling, business rules, integrations, and payments | Node.js, NestJS, Express, Sequelize, MySQL |
| 📱 **[FitCPX Student App](https://github.com/Allyyssoonnn/fitcpx-student-app)** | Student-facing app for workouts, assessments, progress, and communication | Flutter, Dart, BLoC |
| 🏋️ **[FitCPX Exercise Library](https://github.com/Allyyssoonnn/fitcpx-exercise-library)** | Independent exercise catalog with search, filters, videos, favorites, and local caching | Flutter, Dart, SQLite |

**Engineering areas covered:** REST APIs, authentication, payment and contract integrations, cloud media storage, notifications, background workflows, and Android/iOS releases.

> The exercise library is a standalone mobile app; the Student App is the companion app for the FitCPX management platform.
