## 🚀 Projetos em destaque — ecossistema FitCPX

Projetei e desenvolvi o **[FitCPX](https://fitcpx.com)**, uma plataforma de software para academias, personal trainers e profissionais de fitness. O ecossistema abrange gestão de alunos, prescrição de treinos, avaliações físicas, agendamento, contratos, assinaturas, pagamentos, relatórios e experiências mobile.

Os repositórios públicos abaixo mostram diferentes partes desse trabalho, com seus **históricos originais de desenvolvimento preservados**:

| Repositório | O que demonstra | Principais tecnologias |
| --- | --- | --- |
| 🌐 **[FitCPX Web](https://github.com/Allyyssoonnn/fitcpx-web)** | Interface web para profissionais e gestão das operações | React, TypeScript, Vite |
| ⚙️ **[FitCPX Backend](https://github.com/Allyyssoonnn/fitcpx-backend)** | API, modelagem de dados, regras de negócio, integrações e pagamentos | Node.js, NestJS, Express, Sequelize, MySQL |
| 📱 **[FitCPX Student App](https://github.com/Allyyssoonnn/fitcpx-student-app)** | Aplicativo dos alunos para treinos, avaliações, progresso e comunicação | Flutter, Dart, BLoC |
| 🏋️ **[FitCPX Exercise Library](https://github.com/Allyyssoonnn/fitcpx-exercise-library)** | Catálogo independente de exercícios com busca, filtros, vídeos, favoritos e cache local | Flutter, Dart, SQLite |

**Áreas técnicas envolvidas:** APIs REST, autenticação, integrações de pagamentos e contratos, armazenamento de mídias na nuvem, notificações, fluxos automatizados e publicação para Android/iOS.

> A biblioteca de exercícios é um aplicativo independente; o Student App é o aplicativo dos alunos da plataforma de gestão FitCPX.
